# FIFA / EA SPORTS FC

Site acadêmico sobre a história e a evolução da franquia FIFA e EA SPORTS FC, desenvolvido por José Luis para a disciplina de Desenvolvimento Front-End para Web.

## Sobre o projeto

O site reúne informações sobre a origem do FIFA, sua evolução, a troca de marca para EA SPORTS FC, trilhas sonoras, modos de jogo, jogadores, times e ligas, evolução gráfica e curiosidades. Também conta com um guia de controles e um formulário de cadastro de fãs.

Desenvolvido em HTML5, com elementos semânticos, links, imagens, áudio, vídeo, tabelas e campos de formulário. Sem CSS e sem JavaScript.

## Estrutura

```text
html/main/   — Página inicial (index.html)
html/pages/  — Páginas de conteúdo
img/         — Imagens
audio/       — Arquivos de áudio
video/       — Vídeos
```

## Pré-requisitos

* Navegador atualizado (Chrome, Firefox, Edge ou Safari)
* Visual Studio Code, de preferência com a extensão Live Server (opcional)
* Git, para clonar o repositório (opcional)

## Como abrir

```bash
git clone https://github.com/joseluisneto2006/unidade1_html.git
cd unidade1_html
code .
```

Depois, abra o arquivo `html/main/index.html` no navegador ou clique em **Go Live** no VS Code. Mantenha as pastas `html`, `img`, `audio` e `video` juntas, porque as páginas usam caminhos relativos.

## Como usar

* Use o menu, igual em todas as páginas, para navegar entre as 11 páginas.
* Na página Trilhas Sonoras, use o player para ouvir as músicas.
* No Formulário, nome de usuário, senha e data de nascimento são obrigatórios. Os dados não são enviados, porque o site não tem servidor.
