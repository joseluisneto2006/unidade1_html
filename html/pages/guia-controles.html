Pronto para entrar em campo

Agora é só jogar

Antes de se cadastrar como fã na próxima página, só falta uma coisa: conhecer os comandos básicos de FIFA e EA SPORTS FC.

Os controles são praticamente os mesmos desde os primeiros jogos da franquia, com pequenos ajustes a cada nova versão. Este guia mostra o essencial para quem está começando agora.

Uma dica antes de começar

Se você nunca jogou, vale entrar primeiro no modo de treino. Lá dá para testar cada comando com calma, sem a pressão de uma partida de verdade.

Comandos de defesa

Recuperando a bola

Defender bem é tão importante quanto atacar. Sem estes comandos, o time adversário passa muito fácil:

  • Desarme: círculo (PlayStation) ou B (Xbox)
  • Carrinho: quadrado (PlayStation) ou X (Xbox)
  • Marcar o atacante (jockey): segurar L2 (PlayStation) ou LT (Xbox)
  • Trocar de jogador: L1 (PlayStation) ou LB (Xbox)

Uma observação importante: o carrinho mal calculado pode resultar em cartão. Use com cuidado, principalmente perto da sua própria área.

Dúvidas de quem está começando

Perguntas mais comuns

Os comandos mudam de um jogo para o outro?

O essencial (passe, chute, sprint) se mantém igual há anos. O que muda de uma edição para outra costuma ser apenas algum comando novo, como dribles específicos.

Dá para jogar com o controle configurado de outro jeito?

Sim. O próprio jogo permite alterar os comandos nas configurações, para quem já tem o costume de jogar de outra forma.
